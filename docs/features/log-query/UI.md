## 4. 信息架构与页面整体布局

### 4.1 桌面端布局结构

页面在 `.content-card` 内自上而下排列：页面标题与说明 → 双 Tab → 查询区 → 列表区 → 游标分页条。桌面端文字线框图：

```text
日志查询（页面标题与一句说明）
┌ 错误日志 Tab ┬ 正确日志 Tab ┐
│ 查询条件区（响应式，宽屏单行，窄屏换行）        │
│   源库▾  源表名[   ]  目标库▾  目标表名[   ]    │
│   同步到目标库时间范围 [________]  [查询] [重置] │
├──────────────────────────────────────────────┤
│ 列表（表格占剩余高度，表头固定）               │
│   固定列：源库、源表名 | 中间可横向滚动列 ...   │
│   固定列：操作（日志详情、原始消息）            │
├──────────────────────────────────────────────┤
│ 游标分页： [上一页]  [下一页]                  │
└──────────────────────────────────────────────┘
```

| 编号 | 规则 |
|---|---|
| LQ-UI-019 | 功能未开放页固定文案：标题“日志查询功能暂未开放”，说明“当前环境尚未启用日志查询功能。如需使用，请联系系统管理员。”；未开放状态下不显示双 Tab、查询区、列表、分页和详情/原始消息按钮；状态检测失败页固定文案：标题“功能状态获取失败”，说明“暂时无法获取日志查询功能状态，请刷新页面或稍后重新进入。”；状态失败页不提供“重新检测”按钮（`LQ-OPEN-13`、`LQ-UI-009`）。 |

### 15.2 状态转换表

| 动作 | 请求条件 | 成功后的状态变化 | 失败后的状态变化 |
|---|---|---|---|
| 首次进入页面 | 错误日志默认条件（当前自然日） | 错误日志 `appliedCriteria`=默认、`requestCursorStack=[null]`、`items`=第一页、`initialQueryAttempted=true` | 保留空列表与初始表单，显示错误，`initialQueryAttempted=true`（已触发首次查询，不代表成功），不自动重试 |
