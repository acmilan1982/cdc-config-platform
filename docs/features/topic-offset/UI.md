## 3. 查询区（TOFF-REQ-021/022/023/024/025/026/027/030/034/035/036/037/040~053）

- 四个条件一行布局：客户端、源库、目标库（多选下拉，均含特殊选项“全部”）、表名（文本输入）。无其他查询条件（TOFF-REQ-021/022）。
- **四个固定名称 `客户端`、`源库`、`目标库`、`表名` 始终可见，紧随各自控件；不得以 placeholder、当前选中值或 Tooltip 代替固定名称（R2 §4.1，TOFF-REQ-117 视觉）。**
- 表名输入框 placeholder 为 `请输入表名`（R2 §4.1）。
- “全部”固定为下拉第一项（TOFF-REQ-050），用哨兵值 `__ALL__` 仅在表单层表示，不传给后端（TOFF-REQ-023）。
- 互斥语义：默认选中“全部”；选择具体项自动取消“全部”；点击“全部”清空具体项；清空具体项后恢复“全部”（TOFF-REQ-024/025）。
- 候选项：
  - 客户端标签 `ID（描述）`；描述为空只显示 `ID`；描述过长省略并悬浮展示完整描述（TOFF-REQ-041/047）。
  - 源库/目标库标签 `ORG（ID）`；`ORG` 为空显示“未定义名称（ID）”（TOFF-REQ-042/043/048）。
  - 停用项保留，标签附“已停用”标记（TOFF-REQ-045/046）。
  - 候选来源全部配置，不从实际 Topic 提取（TOFF-REQ-040）；每次查询/刷新读取最新（TOFF-REQ-052）。
  - 已生效筛选 ID 刷新期间被删除：不清除，选项区临时显示“ID（配置不存在）”，清除/重置后消失（TOFF-REQ-053/051）。
- 按钮：
  - 查询：提交草稿→回到第 1 页（TOFF-REQ-035/091）。
  - 重置：表单恢复三个“全部”+空表名；**不立即查询**（TOFF-REQ-037）。
- 草稿与列表分离：修改条件但未点“查询”，列表不变化（TOFF-REQ-036/039）；表名输入在提交前去首尾空格（TOFF-REQ-030）。

## 4. 工具栏（TOFF-REQ-020/092/103/104/105/107/108/114，R2 §4.2/4.3）

工具栏明确分为**左组与右组**（`justify-content: space-between` 两端分布；窄窗口允许整组响应式换行，组内顺序不变）：

```text
左组：共 {total} 条　△ 其中 {unparseableTotal} 条 Topic 格式无法解析
右组：60 秒自动刷新　|　最近成功刷新：{HH:mm:ss}　[立即刷新]
```

| 分组 | 元素 | 规则 |
|---|---|---|
| 左组 | 结果总数 | `共 {total} 条`（过滤后全集，TOFF-REQ-092） |
| 左组 | 无法解析警示 | `其中 {unparseableTotal} 条 Topic 格式无法解析`；`unparseableTotal` 为完整查询结果的无法解析总数，非当前页（TOFF-REQ-020、TOFF-AC-018）；前置橙色三角警示图标（Element Plus `WarningFilled`，不新增图片资源）；**`unparseableTotal = 0` 时图标与整段文案均不显示**（R2 §4.2） |
| 右组 | 自动刷新状态 | 常显“60 秒自动刷新”（可含状态点/转圈），自动刷新进行中不过度闪烁（TOFF-REQ-112） |
| 右组 | 最近成功刷新时间 | `最近成功刷新：{HH:mm:ss}`：页面成功取得数据的本地时刻，非数据库 `UPDATED_AT`（TOFF-REQ-114、TOFF-AC-098）；与自动刷新状态之间用细分隔线 `|`；尚未成功时不显示分隔线与该时间 |
| 右组 | 立即刷新 | 按钮；按已生效条件+当前页轻量刷新；成功后重计 60s（TOFF-REQ-104/108/110） |
| 右组 | 刷新失败 | 自动刷新失败不弹堆叠提示，工具栏内联弱提示（TOFF-REQ-113）；保留原数据（TOFF-REQ-111） |

- “立即刷新”必须与自动刷新、最近成功刷新时间保持为右组同一逻辑组，不得单独漂移到另一行。

## 6. 同步对象单元格

### 6.1 可解析（TOFF-REQ-054/055/056/057/058/059/060/061，R2 §4.4）

固定两行：

```
第一行：{CLIENT_ID} · {SOURCE_ORG} → {TARGET_ORG}
第二行：{SCHEMA}.{TABLE}
```

示例：

```
hosp-012 · 孝感市第一人民医院 → doris库
SPT_HIS_2023.OPT_HANDLEDETAIL_EXE
```

符号与内容语义：

- 中点 `·` 是客户端与当前源库的**中性关联分隔符**，不表示数据流向；第一行**有且只有一个** `·`。
- 唯一的 `→` 只表示**源库到目标库**的数据流向；第一行**有且只有一个** `→`。
- 行内不得重复显示“客户端”“源库”“目标库”三个文字标签；不得使用英文句点 `.` 代替中点；不得使用括号把源库包在客户端后面。
- 客户端段只显示 ID，不显示描述（TOFF-REQ-055）。
- 源库/目标库段显示 `DATA_SOURCE_ORG`（TOFF-REQ-056）；`ORG` 为空显示“未定义名称”（TOFF-REQ-059）。
- 状态标记紧邻其所属段（第二段用小标记）：
  - 配置存在且启用：不显示标记。
  - 配置存在但停用：名称或 ID 后标记“已停用”（TOFF-REQ-057）。
  - 配置不存在：显示 Topic 中的原始 ID 并标记“配置不存在”（TOFF-REQ-058）。
- 内容过长省略；单元格仍**严格保持两行**，不换为一行/三行（TOFF-REQ-060）。
- 悬浮展示完整原始 Topic（TOFF-REQ-061/018；时序与单实例见 §6.3）。
- 第二行文本 `Schema.表名` 由解析结果拼接展示（仅展示，不写回，TOFF-REQ-013）。

### 6.2 无法解析（TOFF-REQ-017/018/019/062）

- 单元格第一行显示文本 `Topic 格式无法解析`（TOFF-REQ-017），不展示任何猜测出的客户端/源库/Schema/表名/目标库（TOFF-REQ-062）。
- Offset、断点更新时间、中心端等其余字段照常展示（TOFF-REQ-016）。
- 悬浮展示：完整原始 Topic（TOFF-REQ-018），并就近提示 `该 Topic 无法按“客户端.源库.Schema.表名.目标库”拆分，请人工核对 Topic 命名。`（TOFF-REQ-019、TOFF-AC-017；时序与单实例见 §6.3）。

### 6.3 同步对象 Tooltip 单实例、延迟与非 enterable（R2 §4.5）

同步对象悬浮 Tooltip 采用受控单实例模型，取代每行各自默认时序：

- 鼠标在同一同步对象单元格连续停留 **350ms**（固定值，代码注释与测试保持一致，300~400ms 区间内）后才显示；**鼠标快速扫过多行时不弹出**。
- **任意时刻最多显示一个**同步对象 Tooltip；新行 Tooltip 显示前必须关闭上一行 Tooltip。
- 鼠标离开当前单元格后**立即隐藏**；Tooltip 内容不可通过鼠标移入继续驻留（非 enterable，`pointer-events: none`）。
- 查询结果替换、翻页、刷新提交或组件卸载时，当前 Tooltip **立即关闭**。
- 长 Topic 设置合理最大宽度并允许安全换行，不得溢出视口。
- 可解析行展示完整原始 Topic；不可解析行同时展示完整原始 Topic 与既有人工核对提示。

## 7. 分页（TOFF-REQ-089/091/092/093/075）

- 固定每页 150 条，无规格选择器；分页栏显示总记录数、当前页码/总页数（TOFF-REQ-092）。
- 查询后回到第 1 页；刷新保持当前页（TOFF-REQ-091/110）。
- 刷新后当前页超过新最后一页 → 跳到新最后一页；空结果回到第 1 页（TOFF-REQ-093）。

## 8. 刷新与生命周期交互

页面状态含：首次加载、查询、轻量刷新、失败、空结果（TOFF-REQ-115/116；DESIGN §7）。

| 场景 | 交互 |
|---|---|
| 首次进入 | 缺省条件自动查询（TOFF-REQ-034/097）；成功后开始 60s 计时（TOFF-REQ-105） |
| 点击查询 | loading 整表态；回到第 1 页 |
| 重置 | 只改草稿；不查询（TOFF-REQ-037） |
| 手工刷新 | 轻量态（不清表）；按生效条件+当前页 |
| 自动刷新 | 60s；轻量态；不清表、不闪烁（TOFF-REQ-103/112） |
| 页面隐藏 | 停止自动刷新（TOFF-REQ-106） |
| 重新可见 | 立即刷新一次并重计（TOFF-REQ-107） |
| 离开再返回 | 恢复上次生效条件与页码；先展示保留结果并立即刷新（TOFF-REQ-099/101） |
| 请求进行中 | 不重叠请求（TOFF-REQ-109） |
| 刷新失败 | 保留原列表（TOFF-REQ-111） |
| 连续自动刷新失败 | 不堆提示（TOFF-REQ-113） |

## 9. 加载、空、错误与配置异常状态

| 状态 | 表现 |
|---|---|

| 配置停用 | 候选与同步对象标记“已停用”（TOFF-REQ-046/057） |

## 10. 响应式与横向滚动

- 序号、同步对象 `fixed="left"`；中右列随可用宽度显示，必要时整表横向滚动（TOFF-REQ-094/095）。
- 窄窗口下列宽不压到不可读（建议同步对象保持可读最小宽度）。
- 时间保持单行（TOFF-REQ-096）；Offset 列建议右对齐等宽，便于纵向比对（TOFF-REQ-079/080）。

## 11. 可访问性与 Tooltip

- 长文本省略（单元格/候选标签）都提供悬浮完整内容：同步对象悬浮原始 Topic；客户端候选悬浮完整描述（TOFF-REQ-047/061/018）。
- 同步对象悬浮 Tooltip 的时序与单实例规则见 §6.3（R2 §4.5）。
- Tooltip 文案使用需求原文，避免歧义（TOFF-REQ-019/067）。
- 状态通过“标记文字 + 颜色”双通道表达（不只靠颜色），停用/不存在/未定义名称均有明确文本（TOFF-REQ-046/057/058/059）。
