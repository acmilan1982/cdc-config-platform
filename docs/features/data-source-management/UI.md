```

├────────────────────────────────────────────────────────────────┤

│ ...     │ ...   │ ...  │ ...   │ ... │ ... │ ...                 │ ...    │ ...          │
```

- **页面标题与操作区**：左上"数据源管理"；右上"新增"按钮。
- **查询区**：三个普通文本输入框——数据源 ID、数据源名称、主机地址；"查询"与"重置"按钮（`DS-REQ-006`/`009`）。三条件均忽略大小写模糊、多条件 AND、先 trim（`DS-REQ-007`/`008`）。重置清空并立即恢复全部有效记录（`DS-REQ-009`）。
- **主表格（无分页）**：一次加载并展示全部 `FG_ACTIVE='1'` 记录，无分页控件、无页码、无"加载更多"（`DS-REQ-005`）。默认按数据源 ID 升序，无其他排序（`DS-REQ-010`）。
- **列清单**：数据源 ID、数据源名称、数据源角色（源库/目标库）、数据库类型、主机地址、端口、Service Name/数据库名、用户名、操作（`DS-REQ-011`）。
- **不得展示列**：密码、`DATA_SOURCE_ORG`、`DATA_SOURCE_BIZ_ATTR`、`DATA_SOURCE_DOMAIN`、`FG_ACTIVE`、创建/更新时间、`SOURCE_APP`（`DS-REQ-012`）。
- **行操作**：编辑；删除；角色为目标库时显示"业务属性"；角色为源库时显示"目标库命名策略"（`DS-REQ-013`）。源库行不显示"业务属性"，目标库行不显示"命名策略"（`DS-AC-008`）。
- **角色展示与按钮判定**：角色列与行按钮按**规范化**角色判定——后端对 `DATA_SOURCE_CATEGORY` 存量忽略大小写识别并返回 `SOURCE`/`TARGET`，前端只按规范化 `SOURCE`/`TARGET` 渲染"源库/目标库"与行操作，不依赖任意大小写写法。
- **双击行 = 编辑**（`DS-REQ-014`/`103`）。
- **不使用**旧方案的新标签页及页面重新聚焦刷新行为（`DS-REQ-105`）。
- 组件：`DataSourcePage.vue`（替换占位页）+ 查询区 + `el-table` 无分页 + 各弹窗。

**追踪**：DS-REQ-001/002/003/005/006/007/008/009/010/011/012/013/014/091/105；DS-AC-001~010/011~019/087/098/100。

## 2. 主弹窗（新增/编辑）（§8.2）

居中的大尺寸弹窗（`DS-REQ-015`），宽约 560–720px，不使用抽屉/新页面/新标签页（`DS-AC-020`）。

**字段顺序与分组（唯一字段集，`DS-REQ-019`）**：

| 分组 | 字段 | 控件 | 必填标识 | 规则 |
|---|---|---|---|---|
| 标识 | 数据源 ID | input | `*` | 必填 ≤32 `[A-Za-z0-9_-]`；编辑可修改 |
| 标识 | 数据源名称 | input | `*` | 必填 ≤30 |
| 角色 | 数据源角色/类别 | select | `*` | `SOURCE` 源库 / `TARGET` 目标库 |
| 角色 | 数据库类型 | select | `*` | 源库仅 `ORACLE`；目标库 `ORACLE`/`MYSQL`/`DORIS`；角色变化导致类型非法时清空（`DS-REQ-024`/`025`） |
| 连接 | 主机地址 | input | `*` | 必填 ≤64，IP/域名/主机名 |
| 连接 | 端口 | input-number | `*` | 整数 1–65535 |
| 连接 | 用户名 | input | `*` | 必填 ≤64 |
| 连接 | 密码 | input-password | 新增 `*` | 新增必填 ≤64；编辑显示掩码（见 §3 密码状态） |
| 连接 | Service Name/数据库名 | input | `*` | 必填 ≤64；Oracle 文案"Service Name"，MySQL/Doris 文案"数据库名"（`DS-REQ-030`） |

- **编辑状态模型**：前端打开编辑弹窗时单独保存不可编辑的 `originalDataSourceId`（原主键）；表单中的"数据源 ID"为可自由修改的新值，不得用作读取持久化旧密码的定位键（`DS-REQ-021`）。
- **端口控件**：端口为数值型 `input-number`，只接受整数 1–65535；提交/展示均为数值（`DS-REQ-027`）。
- 全部用户输入字符串（除业务属性外）保存前 trim（`DS-REQ-031`）。
- **不得展示/编辑**：`DATA_SOURCE_ORG`、`DATA_SOURCE_DOMAIN`、`SOURCE_APP`、`FG_ACTIVE`、时间字段；`DATA_SOURCE_BIZ_ATTR` 走独立弹窗（`DS-REQ-020`/`083`）。
- 密码编辑状态：未修改 → 请求体不含 `password`；已修改 → 发送 trim 后新密码（`DS-REQ-045`）。
- 底部按钮：**测试连接**、取消、保存；保存成功关闭并刷新主列表（`DS-REQ-018`）；请求处理中禁用相应按钮（`DS-REQ-017`）。
- 未保存修改关闭 → 二次确认放弃（`DS-REQ-016`）。
- 冲突/校验失败：展示清晰业务消息（`DS-REQ-036`），不暴露堆栈/密码（`DS-REQ-100`/`107`）。

**追踪**：DS-REQ-015/016/017/018/019/020/021/022/023/024/025/026/027/028/029/030/031/036/043/044/045/046/047；DS-AC-020/021/022/023/024~035/036/037/039/040/048/049/050/051/052/095/096/102/105。

## 3. 连接测试交互（§8.3）

新增与编辑弹窗均提供"测试连接"按钮（`DS-REQ-048`）。

- **倒计时文案**：点击后按钮进入禁用态，显示剩余时间 `10, 9, 8, ..., 0` 秒（`DS-REQ-055`）。
- **测试中禁用**：按钮禁用，防止重复点击（`DS-REQ-055`/`101`）。
- **提前返回**：后端提前返回结果时立即停止倒计时（`DS-REQ-056`）。
- **到 0**：显示超时状态，并忽略之后到达的迟返回结果，不覆盖超时状态（`DS-REQ-057`）。
- **迟响应处理**：采用请求代次/序列机制，仅当代次匹配且未超时、未修改连接字段时生效（`DS-REQ-057`/`060`；实现见 `DESIGN.md` §6）。
- **成功**：明确显示"连接成功"（`DS-REQ-058`）。
- **失败**：显示脱敏简短原因（如"认证失败"/"不可达"/"超时"），不返回原始堆栈、密码或敏感连接信息（`DS-REQ-059`/`107`）。
- **字段修改失效**：修改主机/端口/用户名/密码/Service Name/类型等任意连接字段后，之前的成功状态立即失效，需重新测试（`DS-REQ-060`）。
- **非前置条件**：测试失败或未测试均可保存（`DS-REQ-049`）。
- **编辑未改密码测试**：请求携带 `originalDataSourceId`（原主键）、`password` 缺席，后端按 `originalDataSourceId` 定位 `FG_ACTIVE='1'` 记录读取持久化密码；修改表单中当前"数据源 ID"后测试连接且密码未修改时，仍使用原记录密码（`DS-REQ-051`/`052`）。
- **关闭弹窗/切换记录**：取消或忽略旧请求结果（倒计时停止、代次失效）。

**追踪**：DS-REQ-048/049/050/051/054/055/056/057/058/059/060/061；DS-AC-053~064/103/104。

## 4. 业务属性弹窗（仅目标库）（§8.4）

- **入口**：仅目标库行显示"业务属性"按钮（`DS-REQ-082`）；点击打开独立弹窗（`DS-REQ-084`）。
- **角色限定**：弹窗仅在规范化角色为目标库时可用；后端独立校验记录 `FG_ACTIVE='1'` 且角色 `TARGET`，角色不符时返回"数据源角色不适用于当前操作"并拒绝读取/保存。
- **编辑器**：普通 JSON 文本编辑器/多行文本框（`el-input type="textarea"`），仅作文本展示与编辑（`DS-REQ-085`）；支持空内容（`DS-REQ-086`）。
- **不做校验**：第一版不做 JSON 合法性、结构、格式或业务字段校验（`DS-REQ-087`）。
- **原样保存**：保存时原样传输，不 trim、不校验（`DS-REQ-088`）。
- **加载/保存/失败**：读取加载态；保存成功后明确反馈并按页面状态刷新主列表（`DS-REQ-089`）；失败脱敏提示 + 重试（`DS-REQ-100`）。
- **关闭确认**：未保存修改关闭弹窗必须确认放弃（`DS-REQ-090`）。
- 弹窗字段：`DATA_SOURCE_BIZ_ATTR` 多行文本；标题含目标库 ID/名称。

**追踪**：DS-REQ-082/083/084/085/086/087/088/089/090/100；DS-AC-065/066/067/068/069/070/095/099。

## 5. 命名策略大弹窗（仅源库）（§8.5）

- **入口**：仅源库行显示"目标库命名策略"按钮（`DS-REQ-069`）；页面/文档统一使用"目标库命名策略/命名策略"表述，不使用"扩展配置"（`DS-REQ-068`）。
- **角色限定**：弹窗仅在规范化角色为源库时可用；后端独立校验 `sourceId` 记录 `FG_ACTIVE='1'` 且角色 `SOURCE`、新目标库 `FG_ACTIVE='1'` 且角色 `TARGET`，角色不符时返回"数据源角色不适用于当前操作"并拒绝列表/保存/删除。
- **独立大弹窗**：打开独立的大弹窗（`DS-REQ-070`），标题显示当前源库 ID 与名称。
- **无分页列表**：展示该源库全部命名策略，不分页（`DS-REQ-071`）。
- **列清单**：目标库 ID、目标库名称、数据库类型、命名策略、前缀、后缀、操作（`DS-REQ-072`）。
- **行操作**：编辑、删除（`DS-REQ-073`）；删除二次确认（`DS-REQ-081`）。
- **同弹窗内表单**：新增/编辑表单在同一大弹窗内部切换/展开，不嵌套第二个弹窗（`DS-REQ-074`）。
- **目标库下拉**：仅 `FG_ACTIVE='1' AND DATA_SOURCE_CATEGORY='TARGET'` 记录（`DS-REQ-076`）；新增默认不选任何目标库（`DS-REQ-077`）；`TARGET_DATA_SOURCE_ID` 每条必填（`DS-REQ-078`）。
- **策略字段联动**：
  - `TABLE_MERGE`：前缀/后缀不要求填写；切换为或保存为该策略时清空前缀、后缀（`DS-REQ-079`）。
  - `CUSTOM_PREFIX_SUFFIX`：显示前缀、后缀，二者均必填并按统一规则 trim（`DS-REQ-080`）。
- **组合键重复提示**：新增/编辑触发 `(DATA_SOURCE_ID, TARGET_DATA_SOURCE_ID)` 重复或存量多条异常时，明确提示并阻止保存（`DS-REQ-064`/`067`）。
- **编辑定位**：编辑策略时按"原目标库 ID"定位（路径 `originalTargetId`）；切换目标库时 UI 展示新目标库并发送新目标库 ID（`DS-REQ-073`；契约见 `API.md` §2）。
- **未保存修改确认**：关闭或切换时确认放弃（`DS-REQ-075`）。
- 成功反馈：新增/编辑/删除成功后给出明确反馈并刷新弹窗列表（`DS-REQ-102`）。

## 6. 通用状态与视觉验收（§8.6）

- **加载态**：主列表与各弹窗提供加载态（`DS-REQ-098`）。
- **空数据态**：无匹配有效记录时提供空数据状态（`DS-REQ-099`）。
- **错误/重试**：查询、加载、保存、删除、测试连接失败后提供脱敏提示与合理重试入口（`DS-REQ-100`）。
- **成功反馈**：成功保存主数据、业务属性或命名策略均提供明确反馈（`DS-REQ-102`）。
- **防重复提交**：请求进行中禁用对应按钮（`DS-REQ-101`）。
- **未保存确认**：所有编辑容器（主弹窗、业务属性、命名策略）未保存关闭均需确认（`DS-REQ-104`）。
- **文本溢出/Tooltip**：超长单元格（主机、Service Name、前后缀等）显示省略号 + Tooltip 完整内容。
- **弹窗层级**：新增/编辑、业务属性、命名策略均使用同一弹窗体系，避免多弹窗叠压错乱；命名策略弹窗内表单展开不嵌套二级弹窗。
- **响应式最低宽度**：主列表在窄屏下保持最小可用宽度（建议 ≥1024px 内容区）；关键操作不被挤压隐藏。
- **禁止自动刷新**：页面不设自动刷新/定时刷新；仅在操作成功后按页面规范刷新（`DS-REQ-098`~`102` 边界）。
- **人工视觉验收检查点**：主列表列与行操作按钮与批准一致；掩码密码显示；测试连接倒计时与禁用；命名策略策略字段联动；所有弹窗居中、尺寸合理、关闭确认符合预期；无分页控件；无新标签页行为。

**追踪**：DS-REQ-098/099/100/101/102/103/104/105/106；DS-AC-093~101/105/106。

### 9.1 主列表两类空状态（DS-REQ-110 / DS-REQ-111）

- 判定依据：以“最后一次实际执行并生效的查询条件”为准，不以尚未点击查询的表单内容判断。
- 有生效查询条件且结果为零：
  - 主提示：“未找到符合当前查询条件的数据源”
  - 辅助提示：“请调整查询条件后重试，或点击上方‘重置’查看全部数据源”
- 无生效查询条件且列表为零：
  - 主提示：“暂无数据源”
  - 辅助提示：引导使用右上角“新增数据源”创建第一条数据源
- 空状态不增加第二个“重置查询”按钮/链接；查询区现有“重置”是唯一重置入口。

### 9.2 可拖动业务弹窗与固定居中确认框（DS-REQ-112）

- 可拖动：新增/编辑数据源、业务属性、目标库命名策略三个业务弹窗。
  - 拖动区域：仅标题栏非控件区域；关闭按钮、输入控件、操作按钮不得触发拖动。
  - 约束：弹窗不得被完全拖出可视区域，至少保留可操作标题栏；浏览器尺寸变化后修正位置；每次重新打开恢复默认居中。
- 不可拖动（固定居中）：删除确认、未保存确认等小型确认框。
