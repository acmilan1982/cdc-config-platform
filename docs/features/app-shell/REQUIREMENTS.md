## 1. 范围与术语

- **范围**：平台页面**外层布局**——固定侧栏、面包屑、页面标签、主内容区、空工作区、独立大屏分流，以及两个管理页（数据源管理、探针端管理）在标签间的**常驻承载与恢复**。
- **范围外**：业务页内部的查询条件、结果表格、行操作、弹窗、业务接口与数据库表结构（归对应业务 Feature 与公共模板）。
- **术语**：
  - **标签**：顶部页面标签条中的一项，以路由 `path` 为唯一键。
  - **常驻承载（in-document）**：已打开的管理页不再随路由离开而从 document 移除，仅在 document 内切换可见性与交互性。
  - **活动页 / 非活动页**：当前路由指向的管理页 / 同一时刻在承载宿主中隐藏保留的管理页。
  - **查询刷新**：同一路径仅查询字符串变化；区别于**浏览器刷新**。

## 2. 安装与固定侧栏

- **AS-REQ-001 固定侧栏**：侧栏 `position: fixed`，宽度固定 220px，始终展开、占满视口高度；**无折叠入口、无折叠动画**。右侧内容区以 220px 左边距让位，侧栏折起不会改变主内容可用宽度。
- **AS-REQ-002 品牌区**：侧栏顶部固定区（高 56px）显示完整平台标题“CDC 配置管理平台”，不随窗口变窄截断为缩略。
- **AS-REQ-003 菜单结构**：菜单来自 [`frontend/src/config/menu.ts`](../../../frontend/src/config/menu.ts)，分为“配置管理”“运行监控”两组；组标题与菜单项文字以该文件为准。
- **AS-REQ-004 菜单选中态与当前路由同步**：当前路由路径对应的菜单项显示为选中态；无论由标签、面包屑返回还是直接导航，选中项都随路由更新。
- **AS-REQ-005 日志查询重复点击**：当前已在“日志查询”页时，再次点击该菜单项触发页面完整重新初始化（既有专项行为），不影响其他菜单项的首次进入判定。

## 3. 面包屑

- **AS-REQ-006 面包屑与路由同步**：顶部栏由当前路由 `meta.group` 与 `meta.title` 渲染面包屑，以“/”分隔；无标题/分组的空工作区不显示面包屑。

## 4. 页面标签：打开、去重、激活

- **AS-REQ-007 首次打开自动建标签**：导航到任一**非 `standalone` 且声明 `meta.title` 的业务路由**时，在导航确认前按“路径 + 标题”打开或激活标签（含首屏、重定向、前进/后退）。`/workspace`（`meta.emptyWorkspace`、无标题）只清除激活态、不建标签，直接加载或刷新 `/workspace` 不会生成空标签；`/large-screen`（`meta.standalone`）不参与标签。
- **AS-REQ-008 按路径去重**：同一路径再次进入只激活既有标签，不新增重复标签。
- **AS-REQ-009 标签激活跟随路由**：当前路由对应的标签显示为激活态；点击标签导航到该路径。
- **AS-REQ-010 不同查询参数不新增标签**：标签以路由 `path`（不含查询字符串）为键；同一路径的不同查询参数共用同一标签，不产生新标签、不重挂载管理页实例。
- **AS-REQ-011 标签键盘操作**：标签列表为 `tablist`；左右方向键在标签间移动、`Home`/`End` 跳首尾，并将焦点移到目标标签；具备可见焦点样式。
- **AS-REQ-012 标签横向滚动**：标签过多时标签条横向滚动；激活标签自动滚动到可视范围内。

## 5. 关闭标签、相邻切换、空工作区、历史

- **AS-REQ-013 关闭非激活标签**：移除该标签，当前页面与激活标签不变，不发生导航。
- **AS-REQ-014 关闭激活标签的相邻选择**：优先激活**右邻**标签，无右邻则激活**左邻**。
- **AS-REQ-015 关闭最后一个标签进入空工作区**：关闭唯一标签后导航到 `/workspace`，内容区显示“暂无打开的页面 / 请从左侧菜单打开页面”，标签条隐藏；可从侧栏重新打开页面。
- **AS-REQ-016 关闭清除滚动记录**：关闭标签时清除该路径在 store 中的滚动记录，重新打开后用户可见位置应为顶部。需区分三层语义：store 删除记录、页面作为新实例重新请求、用户最终看到的滚动位置；本轮真实浏览器实测覆盖场景见 AS-AC-018 与 DESIGN §6。
- **AS-REQ-017 前进/后退**：浏览器前进/后退时标签与激活态随路由同步；进入 `/workspace` 时清空激活态。
- **AS-REQ-018 关闭激活标签不重复挂载/请求**：关闭当前活动管理页标签时，在标签移除与路由跳转之间不出现页面临时重挂载，也不额外发起列表请求（见 DESIGN §4 的保留窗口机制）。

## 6. 两个管理页的常驻承载与恢复

- **AS-REQ-019 按需挂载**：数据源管理与探针端管理**首次实际打开**时才挂载到承载宿主，未打开不预挂载。
- **AS-REQ-020 原位保留**：切到其他页面时，已打开的管理页保留真实 DOM、有效布局宽度与自身滚动位置，不因离开而卸载。该保留以 `MainLayout` 持续挂载为前提：同一浏览器标签内进入 `/large-screen` 会使 `App.vue` 卸载 `MainLayout`，已打开的常驻页实例与标签随之销毁；返回公共布局后按当前 URL 重建。
- **AS-REQ-021 状态恢复**：切回管理页时，筛选条件、当前结果、滚动位置、横向滚动位置与行选中态按离开前保留（因为实例未被销毁重建）。
- **AS-REQ-022 隐藏页隔离**：非活动管理页不可见、不可点击、不可聚焦、不进入可访问性树（`visibility:hidden`、`pointer-events:none`、`inert`、`aria-hidden`）；其菜单/浮层不残留可见态；命中测试落在活动页。
- **AS-REQ-023 关闭释放**：关闭管理页标签后释放其实例；隐藏页不撑高内容区纵向滚动范围（滚动范围只由活动页决定）。
- **AS-REQ-024 切换零列表请求**：两个已打开管理页之间切换不产生列表 GET，也不重复挂载页面实例。
- **AS-REQ-025 滚动恢复**：以 `.content-area` 为唯一纵向滚动容器；切换标签时保存离开页面的 `scrollTop`，在目标页渲染后还原。

## 7. 普通页与监控页

- **AS-REQ-026 普通页切换即卸载**：除两个管理页外的页面在离开时卸载、返回时重建；数据订阅、中心端配置等每次进入按原有数量发起自身列表请求。
- **AS-REQ-027 监控页轮询停止**：带轮询的监控页（如 CDC 节点状态）离开后停止轮询；重新进入时按既有节奏重新启动。

## 8. 独立大屏与窄窗边界

- **AS-REQ-028 独立大屏**：`/large-screen`（`meta.standalone`）由 `App.vue` 直接渲染，不加载公共布局（无侧栏、面包屑、标签条），页面自身全屏渲染。
- **AS-REQ-029 窄窗边界**：窗口变窄时侧栏保持 220px 不折叠；右侧内容区允许收缩（`min-width: 0`）而不撑破布局；承载宿主裁剪隐藏页的纵向溢出，隐藏页宽度与激活态一致。
- **AS-REQ-030 稳定滚动条槽位（按路由显式声明）**：仅当路由声明 `meta.stableScrollbarGutter === true` 时，`.content-area` 启用 `scrollbar-gutter: stable`；未声明或非严格 `true` 的路由保持浏览器默认行为，不做运行时宽度补偿。当前仅“源库快照状态”声明。

## 9. 刷新与重开的语义（以源码核对）

- **AS-REQ-031 浏览器刷新**：标签状态与滚动记录仅保存在本次页面会话内存中，不持久化。刷新浏览器后按**当前 URL** 重建：当前 URL 为带 `meta.title` 的业务路由时，只有该页一个标签；为 `/workspace` 或 `/large-screen` 时不会生成标签。滚动从顶部开始；此前已打开的其他标签不保留。
- **AS-REQ-032 查询刷新（同路径不同查询参数）**：不新增标签、不重挂载管理页实例；由于内容区滚动 watch 以 `route.path` 为键，仅查询字符串变化不触发路径级滚动保存/恢复。可观察检查：在已滚动的管理页上仅改变查询字符串，标签数量不变、宿主实例不重建、`.content-area.scrollTop` 不被导航重置。页面内“查询”按钮属于页内请求，不改变路由；浏览器刷新按 AS-REQ-031 另行处理。
- **AS-REQ-033 关闭后重开**：先关闭再重新打开，视为新实例：管理页重新挂载并发起一次列表请求，用户可见滚动位置为顶部；普通页同样重建。本轮 5202 实测：关前 `scrollTop=4873`，重开新增 1 次列表 GET，两帧及 0.5/1.5s 后均为 0（见 AS-AC-018）。

- **三层区分（滚动与重开）**：① store 是否保留滚动记录；② 页面是否作为新实例重新挂载并发起列表请求；③ 用户最终看到的滚动位置。①与②是实现事实，③才是验收口径。关闭时 `close()` 先删除记录，但紧随其后的路由切换仍会执行一次“保存离开页 `scrollTop`”，该路径记录可能被再次写回；重开能否回到顶部，取决于恢复写入发生时新实例是否已具备完整滚动高度。本轮 5202 实测为顶部（AS-AC-018），结论绑定当次挂载与请求时序，不作为跨实现保证。
