3. 边界冲突（这是本次纠正的唯一实质原因）
================================================================

R0 提示词明确要求正式验收任务**不得主动执行 ZooKeeper CLI、不得读取节点**。
上述 `ls /bsoft-cdc/clients` 是一次由任务主动发起的 CLI 节点读取，因此**违反**该任务边界。
该违反与“环境是否只读”无关：即便只读，任务主动读取本身即被禁止。

R0 记录中把该探测写成 “ZooKeeper environment (read-only availability probe only)”、
“ZooKeeper 仅只读”，属于**笼统写法**，掩盖了“任务主动读取 + 边界违反”这一事实。
