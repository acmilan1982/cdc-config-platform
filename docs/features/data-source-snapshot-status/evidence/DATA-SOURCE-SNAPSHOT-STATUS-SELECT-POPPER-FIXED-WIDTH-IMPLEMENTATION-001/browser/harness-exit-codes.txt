# 浏览器几何验证脚本：退出码来源与原始日志命名说明

- 说明：本项目 `.gitignore:30` 忽略全部 `*.log`，按任务提示 §12 “若 `.log` 被忽略，应保存为明确命名的 `.txt` 原始日志”，
  所有原始日志均以 `.txt` 命名保存在本目录；内容与采集时逐字节一致（复制后 SHA-256 相同，复制后已删除同名 `.log`）。

## 复核命令（在 evidence 目录下执行）

```bash
grep -Hn 'EXIT' browser/*.txt
node -e 'const m=JSON.parse(require("fs").readFileSync("browser/matrix.json","utf8"));console.log("matrix.json OK viewports="+m.viewports.length+" reps="+m.reps)'
```
