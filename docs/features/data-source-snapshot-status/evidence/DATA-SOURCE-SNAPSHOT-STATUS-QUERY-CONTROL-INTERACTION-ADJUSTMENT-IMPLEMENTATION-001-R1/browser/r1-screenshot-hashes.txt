2) r1-<mode>-tooltip-tag-{1,2}-{1700x920,1920x1080,2560x1440}.png 同 mode 内三 viewport 相同:
   原因: tooltip 为 position:fixed，裁剪区域=下拉框与 tooltip 的并集；在 >=1700 宽度下
         控件几何不随视口变化，故裁剪像素一致。1280 因换行而不同（符合预期）。
3) r1-<mode>-clear-<vp>.png 与 r1-<mode>-reset-<vp>.png 在部分 viewport 相同:
   原因: clear 与 reset 的查询栏几何被证明逐字节相同（states.clear_to_all 与 states.reset
         的所有 rect 相等）；整页像素是否相等取决于查询栏下方数据表重载瞬间的帧，
         属表体区域时序差异，不在 R1 范围内。此为偶发相同，非声明不变量。

  - initial vs longest: 4 viewport x 2 mode 全部不同
  - collision-cand-A vs collision-cand-B (synth): 4 viewport 全部不同
