## 2. 验收结果状态模型

| 状态 | 含义 |
|---|---|
| `NOT_RUN` | 尚未执行，不能推定通过（所有用例初始状态） |
| `PASS` | 已执行且符合预期，须附证据 |
| `FAIL` | 已执行且不符合预期，须记录失败点 |
| `BLOCKED` | 受环境或前置条件阻塞，须记录阻断原因 |
| `DEFERRED_UNTIL_*` | 经批准延期到明确后续阶段 |
