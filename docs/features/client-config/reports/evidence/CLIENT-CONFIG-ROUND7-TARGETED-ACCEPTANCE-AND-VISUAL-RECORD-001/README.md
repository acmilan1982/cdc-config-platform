## 关键实测（脱敏）

### `CCFG-AC-010`（采集数据源列，宽度自适应 / `+N`）

- 7 源样本行在同一浏览器、同一缩放下跨宽度：`1920×1080` → 直接展示 `5`、`+2`；`1440×900` → 直接展示 `1`、`+6`；`900×800` → 直接展示 `1`、`+6`（与既有只读补测 `probeA` 的 `1920/1440/1280/1100/900` 五宽度观察一致）。
- 所有带 `+N` 的行 `+N` 数值 = 未直接展示数（`plusMatchesHidden=true`），直接展示数恒 `≤6`，全部行**单行不换行**；常规行高恒 `48px`（歧义行 `52px`），无单元格溢出。

### `CCFG-AC-155`（行高对照）

- `/config/client` 共 16 行：**15 条常规行**在 `1920×1080`／`1440×900`／`900×800` 均为 `48px`；**1 条歧义行** `52px`。
- **未出现“超长内容行”样本**：全部常规行在各宽度均为单行 `48px`，无换行、无额外撑高 → 自适应观察组仅覆盖“异常/歧义提示行”，`超长内容行` 组**未覆盖**。

### `CCFG-AC-156`（三点入口）

- 命中区 `28×28px`、圆角 `6px`、主色 `rgb(64,158,255)`、光标 `pointer`、hover `rgb(236,245,255)`；位于本行操作单元格内（`boxInsideCell=true`）、行盒内（`boxInsideRow=true`）、**行内垂直居中**（`vCentered=true`）；常规行 **未**因入口额外撑高（`48px`）。
- 真实键盘 `Tab` 第 `7` 步到达三点入口，`:focus-visible` 为 `outline: 2px rgb(64,158,255)` + `outline-offset: -2px`（**内嵌**）。
- 只读回归（探针 D）：单击固定选中（底色 `rgb(225,228,232)`）→ 再次点击取消 → 再次点击固定 → 点击他行转移；悬停他行**不**改变固定行；悬停底色 `rgb(244,244,245)`（与第六轮一致）。
- 菜单隔离：点击三点入口打开菜单 `["停用","删除"]`，**未**打开编辑弹窗、**未**切换固定选中；双击行内容进入编辑弹窗（**未**提交）。按 `Esc` 关闭行为在 headless 下未见稳定关闭（**不**据此判定缺陷，属自动化边界）。
- **未覆盖**：`启用/停用`成功后按稳定 ID 重选、以及由写操作触发的列表重载竞态——均属**写路径**，只读边界内**不可实测**，本轮不下结论。

### `CCFG-AC-157`（显式 opt-in / 未启用页零变化）

- opt-in 辅助类规则**恰 4 条**，**全部**限定在 `.lt-main-table` 作用域内，**无** `!important`（`anyImportant=false`、`allScopedToMainTable=true`）。
- `/config/client` 三点入口可访问名称 `更多操作：<ID>`、`role=button`、`tabindex=0`、键盘可达。
- 只读对照页 `/config/data-source` **零变化**：`36` 行常规行高 `48px`、`lt-row-action__cell`/`lt-row-action__ellipsis` 计数均为 `0`、仍为 `更多`**文字**入口、末列内边距 `12px/12px`、单元高度 `23`、`overflow:hidden`、文件**未修改**。
- **未覆盖**：三点触发器**当前无可观察禁用场景**（提交处理中禁用的是**菜单条目**），`disabled` 子项**不适用且无法构造**；本轮**未**人为制造禁用态，并建议独立基线澄清（见报告 §5）。
