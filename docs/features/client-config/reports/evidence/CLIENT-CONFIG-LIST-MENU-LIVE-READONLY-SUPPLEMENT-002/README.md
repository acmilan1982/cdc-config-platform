## 本轮性质与边界

本任务按提示词明确授权，仅启动缺失的前后端服务（不构建），随后在真实浏览器中
对 `/config/client` 做只读观察。已启动并保持运行：

- 后端：`java -jar target/cdc-config-platform-backend-1.0.0-SNAPSHOT.jar`，PID `8210`，监听 `*:8080`；
- 前端：`npm run dev -- --host 0.0.0.0 --port 5173`，PID `8371`，监听 `0.0.0.0:5173`。

浏览器 context 级 `/api/**` 门禁：GET/HEAD/OPTIONS 放行，其余方法 abort 并计数；
两视口实测 `nonGetAttempts=0`。只打开行菜单与启用/停用确认框并**取消**，
未点击任何最终确认按钮，未执行启用/停用/删除，未创建或修改样本。
