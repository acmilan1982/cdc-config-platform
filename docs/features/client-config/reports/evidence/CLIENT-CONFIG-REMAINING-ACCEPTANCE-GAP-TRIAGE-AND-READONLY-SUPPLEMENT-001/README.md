# 探针端管理剩余验收缺口盘点与只读补测 · 脱敏证据索引

本目录为任务 `CLIENT-CONFIG-REMAINING-ACCEPTANCE-GAP-TRIAGE-AND-READONLY-SUPPLEMENT-001` 的**脱敏、可追溯**证据。

## 本轮定位

- 对 `/config/client`（探针端管理）**当前 `BLOCKED`（72 条）与 `NOT_RUN`（15 条）**验收用例做**逐 ID 缺口盘点与分类**，并**仅对新发现且当前可构造的只读缺口**做真实浏览器只读补测。
- **不是** 157 条整体验收收口；**不是**写路径授权；**不是**其他页面（含 `/config/data-source`）的改造或迁移授权。
- **本轮未改动产品代码 / 测试 / 共享 CSS / 模板基线 / 其他功能文档 / 历史报告**；未提交任何有效新增或编辑表单、未点击启停或删除最终确认、未建夹具、未访问或写入数据库 / ZooKeeper / Kafka；**未启停**项目负责人既有服务。

## 真实只读浏览器补测（本轮）

- 浏览器：Playwright 随附的**无品牌 Chromium** `147.0.7727.15`（headless）。
- 视口：探针 A 覆盖 `1440×900` 与 `1920×1080`；探针 B/C/F/G 为 `1440×900`；探针 D 为 `1920×1080`；探针 E 为 `1920×1080`。
- 服务：仓库**既有、非本任务启动**的开发前端 `http://127.0.0.1:5173`（Vite，按磁盘源码即时提供当前 HEAD 内容）与后端 `http://127.0.0.1:8080`。补测前已核对：Vite 进程 `18651`（监听 `0.0.0.0:5173`，启动于 `13:39:24`）、后端 java 进程 `22643`（`*:8080`）；`GET /config/client` → `200`、`GET /api/clients` → `200`。
- **零写**：导航前在网络层安装拦截，`/api/**` 的 `GET/HEAD/OPTIONS` 放行、`POST/PUT/PATCH/DELETE` 一律 `abort('blockedbyclient')` 并计数。探针 A~G **每条**的实测**非 GET 拦截计数均 = 0**（各 `gap-readonly-results-*.json → writeInterception.nonGetAttempts`），到达后端的非 GET 请求数亦为 `0`（`attempts: []`）。

## 关键实测（脱敏）

- **列表结构**：表头 `序号｜探针 ID｜探针描述｜采集数据源｜数据源数量｜操作`；**无“状态”列**；序号 `1..16` 连续；最右 `操作` 列为 `position:sticky; right:0`（固定列）。
- **分页缺席**：`.el-pagination` 计数 `0`、无每页条数选择器、页面仅一处 `共 16 条`。
- **查询/重置**：查询条件为关键词 + 状态；**无刷新按钮**；重置只清空条件、**不自动查询**（`afterResetNoQuery` 仍 `0` 行，随后查询 `16` 行且序号重新 `1..16`）。
- **行高**：`1440×900` 与 `1920×1080` 均为 `{48px: 15, 52px: 1}`，`wrappedRows: []`（**不存在**“超长内容行”样本）。
- **`更多` 菜单**：圆角 `8px`、阴影 `rgba(0,0,0,.12) 0 6px 16px, rgba(0,0,0,.06) 0 2px 8px`、菜单内边距 `4px`、条目 `6px 12px`/字重 `400`；`删除` 与上方 `停用/启用` 之间为独立 `li[role=separator]`（`1px solid`、`margin 4px 0`）；`删除` 红 `rgb(245,108,108)`、`停用` `#b45309`、`启用` 中性 `rgb(96,98,102)`；Hover/键盘焦点均为浅蓝填充 `rgb(236,245,255)`，危险/警告文字色**不被覆盖**。
- **入口与弹窗**：`新增探针` 位于结果区头部**最右**；无复选框/多选/批量入口/已选提示；弹窗宽 `900px`、三处标签-控件间距恰 `12px`、控件左缘对齐、ID `maxlength=32`、描述提示 `探针用途描述（最多 256 个字符）`；提交按钮常态 `#09090b` 白字 `6px`/`500`，`取消`/`自动生成`/`修改探针 ID` **未变黑**；输入 `40`→`32`、描述 `300 汉字`→`256`；非法 `ab cd@中文` **未被静默改写**，提交给出字段级格式错误且**未产生网络写**。
- **确认框**：启用确认 `customClass cc-confirm--enable`、标题 `启用探针`、正文 `确定启用探针 {探针ID} 吗？`、按钮 `取消/启用`；主按钮**非悬停**常态底色 `rgb(39,39,42)`（鼠标移开仍为该值），`取消` 后 `confirmCanceled=true`、写请求 `0`。
- **环境样本现状（本轮关键发现）**：当前库里**无 `FG_ACTIVE='1'`（启用）行**；异常值样本存在（`异常：X`，红色 11px/700，紧跟探针 ID，`6px` 间距）；数据源候选池 `13` 项中**仅 `1` 项可选**、`12` 项因“已分配/ID 含逗号”不可选 → 多选类用例（`自动生成` 多源连接、≥2 可选源、重复分配等）在本环境**样本缺失**。

## 脱敏处理

- 探针业务 ID 一律替换为 `<ID>`；机构/数据源取值替换为 `<ORG>`。
- 类名中的 Element Plus 内部列序号保留原样（无语义）。
- **不**含数据库连接信息、内网主机/端口、账号口令或令牌、真实业务数据、任何截图。

## 判定边界

- 浏览器证据为**本机真实无头 Chromium 只读核对**（非 jsdom、非静态推导）。
- 本证据只支撑**只读**范围内的事实，**不**覆盖写路径；**不**等于正式验收整体结论，也**不**替代项目负责人对其实际观察范围之外的判断。
