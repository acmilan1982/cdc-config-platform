### 5.1 `CCFG-AC-013` — 数据源机构名/原始 ID 回退语义（**复审点名**）

- **现行定义缺口**：定义要求机构名称无法取得时以**原始数据源 ID** 回退。
- **原始证据**：`013-part@accC` 展示的是**能取得机构名**（异常 Tooltip 主信息为机构名称）的冲突 Tooltip；`097@accG` 是历史逗号歧义行的拆分片段，未经核对不能当作“机构名缺失时按原始 ID 回退”。
- **判定**：全包无“机构名缺失 → 回退原始 ID”样例。`106@accC` 的 `orgMissingItems=0`、`accH` 备注“机构名缺失分行在当前数据集不可构造、未执行”，共同证明**夹具缺失**。
- **与 `106` 的关系**：R2 §5.10 已因“缺机构名项以原始 ID 作主信息”的同一分支不可构造而下调 `106`；`013` 含同一必要分支，R2 保留 `013` 与下调 `106` 自相矛盾。本轮据同因将 `013` 下调。**触发轴 B。**

### 5.2 `CCFG-AC-098` — 6 / ≥7 数据源两类探针与三视口（**复审点名**）

- **现行定义缺口**：PRE 要求**恰好 6 个**与 **≥7 个**数据源两类探针；STEP 要求在 1440×900、1920×1080 与缩窄窗口下观察单行直接展示数量与 `+N` 自洽。
- **原始证据**：`098@accG` 仅命中 `≥7` 一类（`total=7` 一条），**恰好 6 个**样本未出现；仅 1440×900 一腿。
- **判定**：两类样本与三条视口腿未齐；不得以公式/代码推断替代实测。**触发轴 C + B。**

### 5.3 `CCFG-AC-100` — 每行三点入口、三态菜单与 Tab 焦点（**复审点名**）

- **现行定义缺口**：STEP 要求在两种桌面视口检查**每一行**三点入口、三态菜单，并用 Tab 聚焦核对**可见焦点**与可访问名。
- **原始证据**：`100-trigger@accD` 仅记 `allIcon`/`ariaOk`/`sampleAria`；`082@accD` 可补三态菜单，但不自动证明双视口与 Tab 焦点。
- **判定**：既无 1920×1080 腿，也未逐一覆盖全部行，更无 Tab 键盘聚焦动作与可见焦点样式/截图；仅 ARIA 名称不足以证明焦点可见。**触发轴 C + D。**

### 5.4 `CCFG-AC-128` — 超长/非法 ID 输入与后端唯一性（**复审点名**）

- **现行定义缺口**：定义分别要求**手工连续键入**与**粘贴**超长 ID、多种非法字符，并核对大小写不敏感唯一性（**含后端校验**）。
