### 3.1 冲突

- `CCFG-DESIGN-078`／`CCFG-UI-066`：行双击由两次 `click` 组成，双击编辑时实现口径为“**先按普通行内容产生一次有效普通行点击**（即固定选中该行）、**再**进入编辑，且**不**因第二次点击反向取消”。
- R1 的 `CCFG-AC-143` 却把“行双击编辑”与三点触发器、菜单项、确认窗口并列进“操作后固定选中**完全不变**”的**行内控件隔离测试**，要求其**不得**改变固定选中——与 `CCFG-DESIGN-078`／`CCFG-UI-066` 直接冲突。
- 同时 R1 的 `CCFG-AC-142` 步骤对双击的观察点较笼统（“观察该行的固定选中状态”），未把“双击→固定高亮且打开编辑、第二次点击不取消”等结果写成**可直接执行与判断**的判定项。

### 3.2 修订后（本 R2 仅此两处定义行改动）

| 条款 | R2 实际修改 |
