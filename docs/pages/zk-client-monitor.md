## 1. 页面定位

### 1.1 功能定位

以只读方式实时展示 CDC 客户端进程的运行状态。每个 `/bsoft-cdc/clients/{client}` 子节点代表一个独立客户端进程，页面以卡片形式展示全部客户端实例。

### 1.2 页面编号与菜单

| 属性 | 值 |
|------|-----|
| 页面编号 | P-008 |
| 菜单名称 | CDC 节点状态 |
| 所属模块 | 运行监控 |
| 菜单路径 | 运行监控 > CDC 节点状态 |
| 页面类型 | 只读监控列表（卡片式布局） |
| 路由路径 | 待前端框架搭建时确定 |

### 1.3 版面形态

- 单页面，不使用弹窗、抽屉、独立详情页或浏览器新 Tab
- 所有客户端同页展示，所有 jobs 默认全部展示
- 不使用折叠、Tab 或分页控件

## 4. 统一当前运行状态规则（已确认）

客户端和 job 的当前运行状态均以各自 `alive` 临时节点是否存在为准：

```text
alive 表示当前是否运行；
status 只表示最后一次上报状态；
只有 alive 存在时，status 才能作为当前状态展示。
```

| 节点 | alive 存在 | alive 不存在 | alive 读取失败 |
|------|-----------|-------------|--------------|
| 客户端 | online=true，状态码/状态描述使用持久化值 | online=false，状态码 `--`，描述 "未运行" | online=null，状态码 `--`，描述 "状态已知" |
| job | running=true，状态码/状态描述使用持久化值 | running=false，状态码 `--`，描述 "未运行" | running=null，状态码 `--`，描述 "状态已知" |

- alive 节点值为 `{}`，不解析其内容，仅判断节点是否存在
- alive 依赖 ZK 临时节点和会话生命周期，是唯一可靠判定依据
- 持久化 status 仅代表最后一次上报状态，不得解释为当前运行状态
- alive 不存在时不产生 warning，不设置 partialFailure
- detailInfo 和 SCN 在 alive 不存在时仍保留最后一次值

## 5. 字段清单

### 5.1 数据来源

所有字段均从 ZooKeeper `/bsoft-cdc/clients` 子树中只读获取。字段与 ZK 节点的映射关系详见 `docs/zookeeper/field-mapping.md`。

### 5.2 客户端级字段

| 序号 | 字段名 | ZK 来源 | 类型 | 页面展示规则 |
|------|--------|---------|------|-------------|
| 1 | 客户端名称 | clients/{client} 节点名 | string | 直接展示，粗体 |
| 2 | 在线状态 | alive 节点是否存在 | boolean | 圆点 + "在线"/"离线" 文字 + 卡片左侧色条 |
| 3 | IP 地址 | ip → ip | string | 直接展示 |
| 4 | 状态码 | status → code | string | alive 存在时展示实际值，不存在时展示 `--` |
| 5 | 状态描述 | status → description | string | alive 存在时展示实际值，不存在时展示 "未运行" |
| 6 | 详细信息 | status → detailInfo | string（多行） | 等宽字体完整展示，保留换行，6 行固定高度，支持复制 |
| 7 | 更新时间 | status → updateTime | datetime | 直接展示 |
| 8 | PID | alive → pid | string | 在线时展示实际值，离线时展示 `--` |
| 9 | 实例 UUID | alive → instanceId | string | 在线时展示实际值，离线时展示 `--` |
| 10 | 启动时间 | alive → startTime | datetime | 在线时展示实际值，离线时展示 `--` |
| 11 | ZK 路径 | 完整节点路径 | string | **不直接展示**，通过客户端名称旁悬浮 Tooltip 显示 |

### 5.3 job 级字段

| 序号 | 字段名 | ZK 来源 | 类型 | 页面展示规则 |
|------|--------|---------|------|-------------|
| 12 | 任务名称 | jobs/{job} 节点名 + 节点数据 dataSourceOrg | string | 优先展示 dataSourceOrg（业务名称），回退展示节点名，带 ZK 路径悬浮 |
| 13 | 运行状态 | jobs/{job}/alive 是否存在 | boolean | 当前运行状态（alive 存在=运行中，不存在=未运行） |
| 14 | 状态码 | jobs/{job}/status → code | string | alive 存在时展示实际值，不存在时展示 `--` |
| 15 | 状态描述 | jobs/{job}/status → description | string | alive 存在时展示实际值，不存在时展示 "未运行" |
| 16 | SCN | jobs/{job}/scn → scn | string | **可为空**，为空时留空，不展示 `0`/`--`/`暂无`/`未知` |
| 17 | SCN 更新时间 | jobs/{job}/scn → updateTime | datetime | SCN 为空时同样留空 |

### 5.4 禁止使用的字段

| 字段 | 原因 |
|------|------|
| CPU/内存/吞吐量/延迟/TPS | ZK 中不存在 |
| 健康评分/趋势图/错误率 | ZK 中不存在 |
| servers 相关字段 | 项目负责人确认暂不处理 |
| signals 节点 | 项目负责人确认已废弃 |
| status.code 枚举映射 | 项目负责人确认不需要完整枚举 |

## 6. 页面布局

### 6.1 整体结构

```
┌─────────────────────────────────────────────────────────────┐
│ 页面工具栏（标题 + 统计 + 刷新控件）                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 客户端卡片 1 ──────────────────────────────────────────┐ │
│ │ 卡片头部：在线状态 + 概要信息行                          │ │
│ │ detailInfo 区域                                         │ │
│ │ jobs 表格                                               │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ┌─ 客户端卡片 2 ──────────────────────────────────────────┐ │
│ │ ...                                                     │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ...（更多卡片）                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 页面工具栏

位置：页面顶部，水平排列。

| 元素 | 位置 | 说明 |
|------|------|------|
| 页面标题 | 左侧 | "CDC 节点状态" |
| 客户端统计 | 标题右侧 | "共 6 个客户端（5 在线 / 1 离线）" |
| 自动刷新下拉 | 右侧 | 下拉选项：10 秒 / 30 秒 / 60 秒，默认 10 秒 |
| 最后刷新时间 | 右侧 | "最后刷新: 2026-07-17 16:30:05" |
| 手工刷新按钮 | 最右侧 | 独立按钮，点击立即刷新，请求未完成时禁用 |

### 6.3 客户端卡片内部结构

每张卡片从上到下：

1. **卡片头部**（标题行）
   - 左侧：在线状态圆点 + "在线"/"离线"文字 + 客户端名称（如 hosp-006，粗体）
   - 右侧：ZK 路径 `ⓘ` 图标（悬浮显示 `/bsoft-cdc/clients/{client}`）

2. **概要信息行**
   - IP 地址、status.code、状态描述、更新时间
   - 第二行：PID、启动时间（在线显示值，离线显示 `--`）

3. **detailInfo 区域**
   - 标题："详细信息"，右侧「复制」按钮
   - 等宽字体（font-family: monospace）
   - 固定高度 6 行（line-height × 6），超出时内部垂直滚动
   - 保留原始换行（white-space: pre-wrap）
   - 自动换行（word-break: break-all）

4. **jobs 表格**
   - 标题："采集任务 (N)"，N 为 job 数量
   - 表格列：任务名称、状态码、状态描述、SCN、SCN 更新时间
   - jobs 按名称升序排列
   - jobs 为 0 时表格显示一行 "(无采集任务)"
   - 当 jobs 数量 > 8 时，表格区域 `max-height` 启用内部垂直滚动
   - 日常 5～6 个 jobs 自然完整展示，不触发滚动

### 6.4 卡片排序

客户端卡片按客户端名称升序排列。

## 7. 在线/离线视觉规格（已确认）

### 7.1 在线状态指示

采用 **圆点 + 文字 + 左侧色条** 方案。

| 状态 | 圆点颜色 | 文字 | 左侧色条 | 附加效果 |
|------|----------|------|----------|----------|
| 在线 | 绿色 (#52c41a) | "在线" | 4px 绿色实线 | 无 |
| 离线 | 灰色 (#bfbfbf) | "离线" | 4px 灰色实线 | 无 |

### 7.2 硬性约束

- 必须同时显示圆点和"在线"/"离线"文字，不能只依赖颜色。
- 离线客户端仍然完整展示所有已知 status、detailInfo、jobs 等节点内容。
- 不得因离线而隐藏或折叠客户端卡片。
- 避免大面积红/绿背景色，保持卡片主体区域为中性色。

## 11. 刷新规格（已确认）

### 11.1 自动刷新

| 参数 | 值 |
|------|-----|
| 默认状态 | 开启 |
| 默认频率 | 10 秒 |
| 可选频率 | 10 秒、30 秒、60 秒 |
| 控件类型 | 下拉选择器 |
| 刷新方式 | 前端定时轮询，重新调用后端 ZK 读取 API |
| 刷新范围 | 全量刷新（所有客户端 + jobs），不做增量 |

### 11.2 手工刷新

| 参数 | 值 |
|------|-----|
| 控件类型 | 独立按钮（图标 + 文字） |
| 触发行为 | 点击后立即发起全量数据请求 |
| 防重复 | 当前请求未完成时按钮禁用（disabled），不重复触发 |
| 成功后 | 更新"最后刷新时间"，不动自动刷新开关和频率 |
| 失败时 | 保持上次数据不变，可给出轻量错误提示（非弹窗） |
| 不影响 | 自动刷新定时器不受手工刷新影响 |

### 11.3 最后刷新时间

- 刷新成功后更新展示的时间戳。
- 格式：`yyyy-MM-dd HH:mm:ss`。

## 14. 客户端统计（已确认）

工具栏显示简要统计信息（项目负责人已确认 ZK-D-Q-008）：

```
共 {total} 个客户端（{online} 在线 / {offline} 离线）
```

- total = 客户端总数
- online = alive 节点存在的客户端数
- offline = total - online

## 15. 状态码展示规则

- status.code 直接读取并展示当前实际值，不预设完整枚举。
- status.description 直接展示。
- 已观察到的值（1002、9001 等）仅为当前示例，不是完整列表。
- 不将 code 映射为固定的中文枚举文本。

---

## 16. 空白/空值处理

| 场景 | 处理方式 |
|------|----------|
| SCN 为空 | 留空 |
| SCN 时间为空 | 留空 |
| jobs 列表为空 | 显示 "(无采集任务)" |
| PID/实例 UUID/启动时间（离线时） | 显示 `--` |
| detailInfo 为空 | 留空（仍保留区域框架） |
| 无网络/ZK 不可达 | 保持上次数据不变，可显示最后一行的轻量错误提示 |

---

## 17. 错误与边界状态

| 状态 | 行为 |
|------|------|
| ZK 连接正常 | 正常展示全部数据 |
| ZK 返回空列表 | 页面展示 "暂无客户端数据" |
| 后端 API 错误 | 保持上次数据，工具栏可显示轻量提示 |
| 刷新中 | 手工刷新按钮禁用，不阻塞页面交互 |
| 部分客户端无 alive | 标记为"离线"，仍完整展示其 status/jobs 等历史数据 |
| 部分客户端无 jobs | jobs 表格显示 "(无采集任务)" |
