## 3. 字段类型、默认值与注释

```sql
SELECT c.TABLE_NAME, c.COLUMN_ID, c.COLUMN_NAME, c.DATA_TYPE, c.DATA_LENGTH,
       c.CHAR_LENGTH, c.CHAR_USED, c.DATA_PRECISION, c.DATA_SCALE, c.NULLABLE, c.DATA_DEFAULT,
       cc.COMMENTS
FROM ALL_TAB_COLUMNS c
LEFT JOIN ALL_COL_COMMENTS cc ON cc.OWNER=c.OWNER AND cc.TABLE_NAME=c.TABLE_NAME AND cc.COLUMN_NAME=c.COLUMN_NAME
WHERE c.OWNER='CDC' AND c.TABLE_NAME IN (/* 14 张表 */)
ORDER BY c.TABLE_NAME, c.COLUMN_ID;
```

> 降级说明：`DATA_DEFAULT`（默认值）在某些版本需 LONG 处理，可用 `SELECT TEXT FROM ALL_TAB_COLS` 降级读取；字符语义取 `CHAR_USED`（C=CHAR 语义 / B=BYTE 语义）。

- 外键专项：`SELECT ... FROM ALL_CONSTRAINTS WHERE CONSTRAINT_TYPE='R' AND TABLE_NAME IN (...)`；本项目 14 张使用表结果为 0 行。

## 5. 索引字段顺序、表达式与分区属性

```sql
SELECT ai.TABLE_NAME, ai.INDEX_NAME, ai.UNIQUENESS, ai.INDEX_TYPE, ai.STATUS, ai.FUNCTIONAL,
       aic.COLUMN_NAME, aic.COLUMN_POSITION, aic.DESCEND
FROM ALL_INDEXES ai
LEFT JOIN ALL_IND_COLUMNS aic ON aic.INDEX_OWNER=ai.OWNER AND aic.INDEX_NAME=ai.INDEX_NAME AND aic.TABLE_NAME=ai.TABLE_NAME
WHERE ai.OWNER='CDC' AND ai.TABLE_NAME IN (/* 14 张表 */)
ORDER BY ai.TABLE_NAME, ai.INDEX_NAME, aic.COLUMN_POSITION;
```

- 表达式索引：查 `ALL_IND_EXPRESSIONS`（WHERE INDEX_OWNER='CDC'）。
- 分区属性：`ALL_PART_INDEXES` / `ALL_IND_PARTITIONS`；本项目 14 张表无分区。

## 6. 表分区、子分区与 LOB

```sql
-- 分区（结果为 0 行表示未分区）
SELECT TABLE_NAME, PARTITION_NAME, HIGH_VALUE FROM ALL_TAB_PARTITIONS WHERE TABLE_OWNER='CDC' AND TABLE_NAME IN (/* 14 张表 */);
-- 子分区
SELECT TABLE_NAME, SUBPARTITION_NAME FROM ALL_TAB_SUBPARTITIONS WHERE TABLE_OWNER='CDC' AND TABLE_NAME IN (/* 14 张表 */);
-- LOB 段（注意 ALL_LOBS 无 INROW 列，避免误写）
SELECT TABLE_NAME, COLUMN_NAME, SEGMENT_NAME, TABLESPACE_NAME, CHUNK
FROM ALL_LOBS WHERE OWNER='CDC' AND TABLE_NAME IN (/* 14 张表 */) ORDER BY TABLE_NAME, COLUMN_NAME;
```

> 踩坑记录：ALL_LOBS 无 INROW 列；ALL_TABLES 无 LAST_DDL_TIME，需经 ALL_OBJECTS；字符型 LOB 的 CHAR_LENGTH 为 4000 上限占位，不代表实际最大长度。

## 9. 表统计信息与数据画像（只读）

```sql
-- 统计信息
SELECT TABLE_NAME, NUM_ROWS, BLOCKS, AVG_ROW_LEN, LAST_ANALYZED FROM ALL_TABLES WHERE OWNER='CDC' AND TABLE_NAME IN (/* 14 张表 */);
-- 精确计数（仅小表/可接受成本表，大表优先用统计信息或受控范围，见 §10）
SELECT 'CDC_LOG_ERROR' AS T, COUNT(*) AS CNT FROM CDC.CDC_LOG_ERROR;  -- 示例：小表精确
-- 码值分布（非敏感字段）
SELECT DATA_SOURCE_TYPE AS VAL, COUNT(*) FROM CDC.CDC_DATA_SOURCE GROUP BY DATA_SOURCE_TYPE ORDER BY 2 DESC;
```

> 大表成本原则：对大规模日志表（如 CDC_LOG_CORRECT）不做全表 COUNT，采用 `NUM_ROWS` 统计信息或受控范围查询（OBSERVED_ESTIMATED）；对小型表才做精确 COUNT（OBSERVED_EXACT）。精确/估算的区分与原因记录于 `DATA_PROFILE.md` 和 `reports/PROJECT-DATABASE-BASELINE-001.md`。

## 11. 文档更新前后自检清单

必须重新读库核验的触发条件已收窄，见 `README.md` §6；普通业务规则调整、前端开发、后端非结构性开发、常规单元测试不得仅因“涉及数据库”强制重新连接数据库。
