# CDC 配置管理平台 — 菜单结构

> 任务编号：PRODUCT_DESIGN_001
> 设计日期：2026-07-03

## 菜单层级树

```
配置管理
├── 数据源管理          ← 默认首页
├── 客户端配置
├── 数据订阅
└── 服务端配置

运行监控
├── CDC 节点状态        ← 数据来源：ZooKeeper
├── 数据源运行状态
├── Topic 偏移量
└── 日志查询
```

## 默认进入页面

系统启动后默认跳转到「配置管理 > 数据源管理」。本期无首页/仪表盘。

## 菜单详情

| 序号 | 菜单名称 | 所属模块 | 对应页面 | 数据来源 | 涉及表 | 读写性质 | 说明 |
|------|----------|----------|----------|----------|--------|----------|------|
| 1 | 数据源管理 | 配置管理 | 数据源管理（主列表 + 扩展配置子页） | Oracle | CDC_DATA_SOURCE, CDC_DATA_SOURCE_EXTEND | 可读写 | 两表合并为一个菜单，不暴露底层表名 |
| 2 | 客户端配置 | 配置管理 | 客户端配置（列表 + 编辑） | Oracle | CDC_CLIENT_MULTIPLE | 可读写 | |
| 3 | 数据订阅 | 配置管理 | 数据订阅（列表 + 详情） | Oracle | CDC_DATA_SUBSCRIBE | 可读写 | |
| 4 | 服务端配置 | 配置管理 | 服务端配置（列表 + 详情含配置项） | Oracle | CDC_SERVER, CDC_SERVER_CONFIG | 可读写 | 两表合并为一个菜单，不暴露底层表名 |
| 5 | CDC 节点状态 | 运行监控 | CDC 节点状态 | ZooKeeper | — | 只读 | 不对应 Oracle 表，前端轮询 |
| 6 | 数据源运行状态 | 运行监控 | 数据源运行状态 | Oracle | CDC_DATA_SOURCE_RUN_STATE | 只读 | 由外部程序维护，前端轮询 |
| 7 | Topic 偏移量 | 运行监控 | Topic 偏移量 | Oracle | CDC_TOPIC_OFFSET | 只读 | 前端轮询 |
| 8 | 日志查询 | 运行监控 | 日志查询（Tab：错误日志 / 正常日志） | Oracle | CDC_LOG_ERROR, CDC_LOG_CORRECT | 只读 | 两表合并为一个菜单，通过 Tab 切换 |

## 菜单命名原则

1. 所有菜单使用业务名称，不使用数据库表名。
2. 多表合并为一个页面时，只保留一个菜单入口。
3. 菜单顺序：配置管理在前，运行监控在后。各模块内按业务重要性和操作频率排序。

## 合并菜单说明

| 菜单 | 合并表 | 合并方式 | 原因 |
|------|--------|----------|------|
| 数据源管理 | CDC_DATA_SOURCE + CDC_DATA_SOURCE_EXTEND | 主列表 + 扩展配置子页 | 两表为 1:1 关系，项目负责人确认合并 |
| 服务端配置 | CDC_SERVER + CDC_SERVER_CONFIG | 主列表 + 详情（含配置项列表） | 两表为 1:N 关系，项目负责人确认合并 |
| 日志查询 | CDC_LOG_ERROR + CDC_LOG_CORRECT | Tab 切换（错误日志 / 正常日志） | 两表结构相同，分别存储失败和成功日志，统一查询入口 |

## 菜单权限标记

本期不开发权限体系，所有菜单对所有用户可见。后续可扩展菜单权限控制。
