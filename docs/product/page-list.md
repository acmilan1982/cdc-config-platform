## 页面类型说明

| 页面编号 | 页面类型 | 选择理由 |
|----------|----------|----------|
| P-001 | 列表 | 数据源为列表型数据，需支持关键词搜索、筛选和批量操作（具体字段待模块设计） |
| P-002 | 子页/表单 | 1:1 扩展配置，适合作为子页或抽屉表单，在主列表中选择数据源后进入 |
| P-003 | 列表 + 编辑 | 客户端配置业务结构相对简单，字段数量有限，当前未发现必须使用独立详情页、主从页面或子页面的业务需求 |
| P-004 | 列表 + 详情 | 列表字段有限，CLOB 字段（表名列表）需在详情页完整展示 |
| P-005 | 详情页 | CLOB 字段内容较长（表名逗号分隔列表），不适合在列表行中展示 |
| P-006 | 列表 | 中心端实例为列表型数据，每行展示基本信息和在线状态 |
| P-007 | 详情 + 配置列表 | 中心端详情包含基本信息和配置项列表，适合详情页内嵌表格 |
| P-008 | 只读监控列表（含节点类型筛选） | 单页面，客户端节点、探针节点及其他节点类型通过"节点类型"筛选切换，不拆分多页面或多菜单。实时监控数据，需自动刷新控件 |
| P-009 | 只读监控列表 | 由外部程序写入的快照状态，只读查询，自动刷新 |
| P-010 | 只读监控列表 | Kafka 消费偏移量，生产环境数百条记录，需支持分页和自动刷新 |
| P-011/P-012 | 只读日志列表（Tab） | 两张表结构相同，用 Tab 切换"错误日志"和"正确日志"，共享筛选条件框架。CDC_LOG_ERROR → 错误日志，CDC_LOG_CORRECT → 正确日志 |

## 页面关系

### 默认进入页面

系统启动后默认跳转到 P-001「数据源管理列表」。

### 主列表 → 子页/详情

```
P-001 数据源管理列表 ──→ P-002 数据源扩展配置（子页）
P-004 数据订阅列表   ──→ P-005 数据订阅详情
P-006 服务端配置列表 ──→ P-007 服务端详情与配置项
```

### Tab 页面

```
P-011 错误日志 (Tab: 错误日志)
P-012 正确日志 (Tab: 正确日志)
─────────────────────────────
  共用：筛选条件（时间范围、数据源、操作类型）
  差异：数据来源（CDC_LOG_ERROR vs CDC_LOG_CORRECT）
```

### CDC 节点状态（单页面 + 节点类型筛选）

P-008 为单页面，通过"节点类型"下拉筛选切换客户端节点、探针节点及其他节点类型。不拆分为多个独立页面或多个菜单。

### 跨模块跳转（已确认）

- 支持从运行监控页面跳转到对应配置详情。
- 仅当运行数据能够唯一定位到一条配置记录时，才显示跳转入口。
- 无法唯一定位时，不显示跳转入口。
- 示例：从 P-009「数据源运行状态」的 DATA_SOURCE_ID 可跳转到 P-001 该数据源的扩展配置。
- 不得设计模糊匹配或让用户自行猜测目标配置。

### 导出功能

第一版不提供导出功能。所有页面均不设计导出按钮。
