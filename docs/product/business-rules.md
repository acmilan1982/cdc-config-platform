# CDC 配置管理平台 — 产品业务规则

> 任务编号：PRODUCT_DESIGN_001 / PRODUCT_DESIGN_002
> 设计日期：2026-07-03
> 最近更新：2026-07-03（根据项目负责人确认固化）
> 来源：项目负责人已确认决策 + 数据库分析已确认结论

## 1. 版本范围

### 第一版包含

- 配置管理：数据源管理、客户端配置、数据订阅、服务端配置
- 运行监控：CDC 节点状态、数据源运行状态、Topic 偏移量、日志查询
- 全部 10 张白名单 Oracle 表 + ZooKeeper 节点状态

### 第一版不包含

- 登录与权限
- 首页/仪表盘
- 导出功能
- WebSocket 实时推送
- CDC 任务控制（启停、重置进度）
- 对 ZooKeeper 的写操作

## 2. 全局交互规则

### 默认页面

- 系统进入后默认跳转到「配置管理 > 数据源管理」

### 只读表规则

以下表对应页面完全只读，不提供新增、编辑、删除功能：

- CDC_DATA_SOURCE_RUN_STATE → 数据源运行状态
- CDC_TOPIC_OFFSET → Topic 偏移量
- CDC_LOG_ERROR → 日志查询（错误日志 Tab）
- CDC_LOG_CORRECT → 日志查询（正确日志 Tab）

允许的操作：查询、筛选、查看详情、手工刷新。

### 刷新规则（运行监控模块）

| 参数 | 值 |
|------|-----|
| 刷新方式 | 前端轮询 |
| 频率选项 | 10 秒、30 秒、60 秒 |
| 默认频率 | 10 秒 |
| 自动刷新开关 | 支持开启/关闭 |
| 手工刷新 | 支持 |
| WebSocket | 不使用 |

### CDC 节点状态页面规则（已确认）

- CDC 节点状态采用单页面展示。
- 客户端节点、探针节点及其他节点类型通过「节点类型」筛选切换。
- 不拆分多个菜单，不拆分多个独立页面。
- 页面保持只读。

### 跨模块跳转规则（已确认）

- 第一版支持从运行监控页面跳转到对应配置详情。
- 仅当运行数据能够唯一定位到一条配置记录时，才显示跳转入口。
- 无法唯一定位时，不显示跳转入口。
- 不得设计模糊匹配或让用户自行猜测目标配置。

### 导出规则（已确认）

- 第一版不提供导出功能。
- 所有页面第一版均不设计导出按钮。

### 菜单规则

- 所有菜单使用业务名称，禁止使用数据库表名。
- 多张表合并为一个页面时，只保留一个菜单入口。
- 菜单顺序：配置管理在前，运行监控在后。
- CDC 节点状态不拆分为独立菜单。

## 3. 合并页面规则

| 菜单 | 表 | 关系 | 页面形态 | 形态选择理由 |
|------|-----|------|----------|-------------|
| 数据源管理 | CDC_DATA_SOURCE + CDC_DATA_SOURCE_EXTEND | 1:1 | 主列表 + 扩展配置子页 | EXTEND 为 DS 的 1:1 补充配置，适合子页/抽屉表单 |
| 服务端配置 | CDC_SERVER + CDC_SERVER_CONFIG | 1:N | 列表 + 详情（内嵌配置列表） | SERVER 为主记录，CONFIG 为配置项集合，适合详情页内嵌表格 |
| 日志查询 | CDC_LOG_ERROR + CDC_LOG_CORRECT | 结构镜像 | 列表 + Tab（错误日志 / 正确日志） | 两表结构相同用途不同，Tab 切换保持查询上下文一致 |

## 4. 日志查询命名规则（已确认）

日志查询菜单采用单菜单、双 Tab：

| Tab | 对应表 | 说明 |
|-----|--------|------|
| 错误日志 | CDC_LOG_ERROR | 未能正常同步到目标库的数据记录 |
| 正确日志 | CDC_LOG_CORRECT | 已成功同步到目标库的数据记录 |

以下名称禁止使用：

- 正常日志
- 纠正日志
- 日志纠正记录

## 5. 页面读写规则

### 可读写页面

| 页面 | 允许操作 | 限制 |
|------|----------|------|
| 数据源管理（P-001 + P-002） | 新增、编辑、删除、查询 | 具体删除前置检查和引用校验留到模块设计 |
| 客户端配置（P-003） | 新增、编辑、删除、查询 | CLIENT_ID 唯一，编辑时不可修改 CLIENT_ID |
| 数据订阅（P-004 + P-005） | 新增、编辑、删除、查询 | 具体字段校验留到模块设计 |
| 服务端配置（P-006 + P-007） | 新增、编辑、删除、查询 | 配置项 IS_EDITABLE=0 的字段在 UI 上禁用编辑 |

### 不纳入页面的字段

以下字段已由项目负责人确认"暂时不用"，不纳入第一版页面：

| 表 | 字段 | 说明 |
|----|------|------|
| CDC_DATA_SOURCE | DATA_SOURCE_DOMAIN | 暂时不用 |
| CDC_DATA_SUBSCRIBE | DATA_TARGET_TABLE | 暂时不用 |
| CDC_DATA_SUBSCRIBE | DATA_TARGET_COMMENT | 暂时不用 |
| CDC_SERVER | DATA_SOURCE_ID | 暂时不用 |
| CDC_LOG_CORRECT | RESULT_DETAIL | 暂时不用 |

### 字典字段展示规则

| 字段 | 规则 |
|------|------|
| DATA_SOURCE_CATEGORY | 统一转大写展示，表单输入自动转大写（取值 SOURCE / TARGET） |
| DATA_SOURCE_TYPE | 下拉选择：ORACLE / MYSQL / DORIS |
| FG_ACTIVE | 展示为"启用/停用"开关或标签 |
| SNAPSHOT_STATUS | 展示为中文标签：SNAPSHOT_COMPLETED→已完成 / SNAPSHOT_RUNNING→运行中 |
| INSTRUCTION_TYPE | 展示为中文：c→增量新增, r→快照读取, u→更新, d→删除, ddl→表结构变更 |
| RESULT_CODE | 展示为：0→成功, 1→异常 |

## 6. 配置保存规则

- 页面当前只负责保存配置到 Oracle 数据库。
- 不负责实时通知 CDC 进程应用配置变更。
- CDC 进程的配置加载机制由现有程序负责。

## 7. 数据安全

- CDC_DATA_SOURCE.DATA_SOURCE_PASSWORD 明文存储和展示（项目负责人确认不加密）。
- 日志页面展示 Java 异常堆栈和 Kafka 原始消息时不做脱敏处理。

## 8. 页面设计原则

1. **字段级规格推迟**：所有页面的具体字段、表单控件、校验规则、删除检查和引用校验，在模块正式开发前单独设计。
2. **禁止自行补充**：不得基于字段名或现有数据自行推断未确认的业务规则。
3. **页面形态不得依赖开发环境当前数据量**：页面设计依据应为业务结构的复杂度、字段数量和实际业务需求，而非当前开发环境的数据量。例如客户端配置采用简单列表页，依据是其业务结构相对简单、字段数量有限、当前无独立详情或主从页面的需求。
4. **结论分级**：所有设计结论必须标注来源：
   - 项目负责人已确认
   - 数据库分析已确认
   - 产品设计建议
   - 待模块开发前确认

## 9. 后续扩展预留

以下功能预留扩展空间但不纳入第一版：

- 登录与权限体系（可在菜单、页面、按钮级别扩展权限控制）
- 首页/仪表盘（可在运行监控基础上聚合关键指标）
- 导出功能（可在后续版本评估）
- WebSocket 实时推送（替换前端轮询）
- CDC 任务控制（启停、重置采集进度等）
